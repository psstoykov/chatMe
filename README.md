# chatMe

[x] This is a small scale texting app, which implements user accounts
[x] Chooose your best friends and add them to your following list
[x] Easy access to private chatroom with any user on the platform

# Public link to app:

https://reactjs-c8cf4.web.app/

# Run on a local computer

[x] Download the full repository

## type the following commands in the order listed below

[x] npm install
[x] npm install react-router-dom
[x] npm run dev

Application should now be running at http://localhost:5173/

# Core functionalities

## Implementation and deployment

[x] this app makes use of firebase as a cloud service in combination with firestore as a database
[x] user authentication is provided by the firebase API

## User/auth

[x] Create an account with email and password
[x] Make use of persistant user authentication for your personal account
[x] Auth guard and user guard are available to help prevent unauthorized access

## Public part

[x] Guest users can access the Homepage, Login and Register
[x] Guest are not able to send messages without having a personal account

## Private part (logged-in users only)

[x] Users can browse the list of available accounts on the platform
[x] Users can click on a person they wish to connect with and start a private chat room
[x] All messages are time stamped, so you always have a reference
[x] Chat is color coded for easy readability
[x] You can choose to follow or unfollow each individual user on the platform. This way you can make a selection of your most used contacts

## My Page (logged-in users only)

[x] Access to your personal page, where a new account password can be chosen
[x] Get account information about your last login and when your account was initially created
[x] You have a combined button/counter for both followers and following. With just a click you can access your personal selection of users
[x] A big delete button if you choose to leave the platform and would like to remove your account permanently
